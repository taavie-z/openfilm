A diagnostic report to paste into an issue. `openfilm doctor` checks what OpenFilm needs on this computer: Node, ffmpeg, the browser films are drawn in and whether it uses the graphics chip, Studio, the data and projects folders, and npm. It also shows which agent ran the command and the last errors in Studio's log. Settings → General → Copy report copies the same report, plus what the browser Studio is open in can do. In the desktop app, it adds each agent's program, version and state. Paths in your home folder show as ~; the report has no keys, accounts or projects.
