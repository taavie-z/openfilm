Studio: an export can be named where it is asked for — a name field beside the folder it goes to, the project's name in it to begin with — instead of every file taking the project's name. A named export keeps the suffixes that tell the files of one export apart (` · 哔哩哔哩`, `(alpha)`, `stills`) and drops the ones that only describe the project (`1080p`, `0-9s`). A name left empty is the project's, as before, and an export that would take a name already there still gets ` 2` rather than being written over.
